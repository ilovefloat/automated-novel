# 32화

은빛으로 떨어지는 미세한 선각과 검붉은 녹이 번갈아 표제지를 내리찍을 때마다 강철판 표면에서 일어나는 마찰열이 극에 달했다. 척추를 타고 반으로 쪼개지듯 울리던 두 갈래 맥박—선우 자신의 뜨거운 가속 맥박과 깊은 어둠 속에서 차갑게 정지해 있던 선대 저자의 기계적 맥동이—마지막 충격음을 내며 표제지 외곽의 테두리를 수직으로 쪼개 놓았다.

가죽처럼 단단하고 건조하게 굳어버린 선우의 등가죽 위로 불길 같은 진동이 뻗어 나갔다.

강철 틀이 가로로 갈라진 수평 균열 틈새에서, 정이나 망치보다 무겁고 육중한 기계음이 터져 나왔다. 솟구쳐 오른 것은 손가락 굵기보다 두꺼운 거대한 강철 제책 바늘들이었다. 바늘귀마다 길게 매달린 무거운 쇠 가죽 끈들이 팽팽하게 죄어들며 공중에서 거친 회전 궤적을 그렸다.

콰직, 콰지직.

표제지 강철판 아래, 압착된 미색 갱지의 층위로 제책 바늘들이 무자비하게 수직으로 꽂혀 내렸다. 단단하게 눌려 있던 본문 원고지 뭉치들이 비명을 지르듯 터져 나가며 수백만 장의 마른 종이가 찢어지는 둔탁한 타격음이 배출 통로 전체를 흔들었다. 아직 활자가 찍히지 않은 여백의 원고지 지층들이 철사와 쇠 가죽 끈에 꿰뚫려 표제지 하부에 촘촘히 밀착되기 시작했다.

그것은 단순한 인쇄가 아니었다. 흩어져 있던 판본의 파편들과 표제지를 하나의 거대한 물리적 덩어리로 묶어 세우는 ‘제책’의 거친 메커니즘이었다.

회전하는 제책 바늘의 무자비한 궤적에 선우의 몸이 휘말려 들었다. 탈구된 채 가슴팍에 고정되어 있던 왼쪽 어깨와, 무두질된 가죽처럼 가라앉은 척추의 살가죽이 솟구치는 쇠줄에 얽혀 들어갔다. 강철 바늘은 거침없이 선우의 늑골 사이 여백 구획을 관통하고, 동시에 표제지 강철 주조틀의 모서리를 깊숙이 꿰뚫었다.

살점이 찢기는 피는 터져 나오지 않았다. 대신 가죽화된 살가죽 틈새로 차가운 백색 금속 증기가 뿜어 나왔고, 뼈 마디마디가 표제지 강철판과 본문 원고 뭉치를 연결하는 거대한 물리적 접합부—책등의 형상으로 고착되어 갔다. 척추가 매연과 종이 지층을 잇는 뼈대로 붙박이는 동안, 선우는 자신이 이 판본 전체를 지탱하는 종이 매체의 접착물로 완전히 소모되리라는 것을 감각했다.

"…아직이다."

목구멍에서 탄화된 가루 냄새가 섞인 웅얼거림이 터졌다. 척추를 두 갈래로 가르는 이중 맥박의 격렬한 충격 속에서, 선우는 오른손 손가락 마디를 쥐어짰다. 여전히 표제지 저자명 음각 바닥에 붙박여 있던 검지 외에, 남은 손가락 마디를 솟구쳐 내리는 제책 바늘의 둥근 구멍 틈새로 강제로 쑤셔 넣었다.

쇠줄의 매끄러운 궤적과 선우의 굳어버린 뼈마디가 거칠게 충돌했다.

쨍강하는 고음의 금속성 비명과 함께 불꽃이 사방으로 튀었다. 강제로 밀어 넣은 뼈의 마찰력으로 인해 일직선으로 낙하하던 제책 바늘의 회전축이 기형적으로 뒤틀렸다. 표제지와 본문 뭉치를 정교하게 바느질하려던 쇠 가죽 끈이 어지럽게 꼬이며 얽혀 들었다. 궤적을 벗어난 철사가 선우의 늑골과 강철 프레임 구석을 불규칙하게 죄어들었다.

날카로운 기계식 고주파음이 배출 통로 내부를 매웠다. 정교하게 조율된 제책 장치가 선우의 뼈 마디가 만들어낸 오차를 감당하지 못하고 삐걱거리며 급격히 회전 속도를 줄였다. 

강철 제책 바늘들은 규칙적인 관통을 멈춘 채, 어지럽게 뒤엉키고 비틀린 기형적인 매듭의 상태로 책등의 중심부에 멈춰 섰다.

표제지 강철판과 하부의 본문 원고지 뭉치, 그리고 늑골과 어깨가 철사에 관통된 선우의 육체가 하나의 단단하고 일그러진 판본으로 묶였다. 선우는 눈 한번 감지 못한 채, 자신의 손가락 마디가 억지로 비틀어놓은 기형적 제책 매듭 사이로 백색의 건조한 금속 증기와 미색 종이 먼지가 새어나오는 광경을 내려다보았다.
